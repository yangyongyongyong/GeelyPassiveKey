# 54. v4.1.7：蓝牙信号实时曲线

日期：2026-11-15，Asia/Shanghai。版本：`4.1.7-min / versionCode 117`。

**范围：只增加可视化，不改变扫描、连接、解锁/上锁阈值或车控。**主页新增原生Canvas RSSI曲线，每500ms读取现有运行态快照并绘制最近60秒走势。

## 1. 曲线内容

| 图形 | 含义 |
| --- | --- |
| 蓝色实线 | 原始RSSI，来自`PassiveKeyService.Status.rssi` |
| 黄色实线 | 当前RssiFilter平滑值`Status.smoothRssi` |
| 绿色虚线 | 当前靠近解锁阈值（默认-75dBm） |
| 红色虚线 | 当前离开上锁阈值（默认-82dBm） |
| 断开区间 | 无服务绑定、无新鲜样本或样本超过3秒时，不连线 |

曲线纵轴固定`-105 ~ -35 dBm`，横轴为最近60秒。卡片摘要同时显示：

- 当前原始值、平滑值、所在区域；
- 最近60秒有效样本数、最小/最大值；
- 当前信号来源（广播/GATT）；
- 最后样本年龄。

## 2. 采样和断点

- 界面原有500ms刷新循环作为唯一采样时钟，不新增后台线程。
- `RssiChartSeries`保留最近60秒、最多160点，内存固定。
- 原始RSSI必须满足`-105 < raw < 0`才算有效；`-127`只作为“无信号”标记。
- 无新鲜信号时插入无效断点，曲线会在空白处截断，不会把无信号画成真实弱信号。
- 曲线只读取状态，不触发`readRemoteRssi()`、不启动/停止扫描、不连接车机、不发送通知按钮。

## 3. 阈值联动

曲线每次刷新读取当前`unlockDbm/lockDbm`。用户在“自定义靠近/离开阈值”中保存后，绿色/红色虚线立即移动，不需要重启服务。

平滑值仅用于展示当前滤波结果；曲线不会把平滑值写回`PassiveKeyLogic`，也不会改变实际解锁/上锁判定。

## 4. 文件与结构

## 7. 使用建议

1. 打开App后保持“车机参数（只读）”与“蓝牙信号实时曲线”同屏观察。
2. 从5米外缓慢靠近，记录曲线跨过绿色阈值的时间。
3. 离开时观察红线、当前平滑值与4.5秒驻留是否一致。
4. 若曲线在贴车之前大量断点，优先检查扫描回调、后台限制和车机广播，而不是继续降低阈值。
5. 曲线是RSSI历史，不是距离标尺；墙体、人体遮挡、手机握持和广播/GATT信道差异都会影响数值。
