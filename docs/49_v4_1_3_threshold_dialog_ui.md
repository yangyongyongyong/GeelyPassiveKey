# 49. v4.1.3：阈值设置弹窗UI与字段解释

版本：`4.1.3-min / versionCode 113`。2026-11-12本地修改与构建，尚未安装手机或发布GitHub。

## 1. 解决的问题

旧“自定义靠近/离开阈值”窗口只有3个EditText，标签仅存在于hint，已有数值填入后hint消失，用户看不到每行用途。还存在这些问题：

- 用固定米数解释RSSI，忽略车型、手机、口袋和遮挡差异；
- 值越负/越接近0有什么效果不清楚；
- 保存错误只显示Toast，系统默认正向按钮仍关闭窗口；
- “恢复默认”立即写配置并关闭，不能先查看推荐值再取消；
- 初值按整数/一位小数显示，会丢掉原有小数阈值或毫秒精度；
- 服务未绑定时原保存分支直接写偏好，与服务绑定时的范围截断不一致。

## 2. 新布局与每项含义

弹窗采用与主页一致的深色卡片主题：标题区、可滚动字段区、固定预览/操作区。三个字段有永久标签、说明、比较符、单位、推荐值和可填范围：

| 项目 | 含义 | 推荐 / 范围 | 调节方向 |
| --- | --- | --- | --- |
| 靠近解锁信号 | 接近信号达到此值或更强，满足信号解锁条件 | `-75 dBm`；`-90`至`-40` | 更负通常更早触发；更接近0需要更靠近 |
| 离开上锁信号 | 信号等于此值或更弱，开始连续离开确认 | `-82 dBm`；`-98`至`-46`，且比解锁值低至少6dB | 更负通常需要走得更远 |
| 离开确认时长 | 持续处于上锁信号区这么久，才满足时间条件 | `4.5秒`；`1.5`至`20秒` | 更长更能抑制短暂衰落，但上锁更晚 |

dBm越接近0越强，例如-70比-75强；不再把这些数值等同固定米数。靠近信号含既有遮挡补偿，离开与近场保护使用未补偿信号。提示只是解释当前规则，不承诺只满足某一条就必然车锁动作：官方就绪、服务开关、行驶/插线、近场保护及会话锁存仍按原逻辑生效。

主页阈值摘要同步分成两行显示真实值，去掉“约3米”，保留原小数精度；自动解锁开关说明也改为“接近信号达到阈值”。

## 3. 交互

- **永久标签**：标题通过`labelFor`关联输入，说明不藏在placeholder；字段错误就在该输入下方，不只给红框。
- **数字键盘**：dBm允许负号/小数，时长允许小数；Next依次移到下项，Done执行同一保存校验。
- **字段解释和推荐值**：蓝色/紫色/青色只表达视觉层级，文字仍完整可读，不只靠颜色辨识。
- **输入预览**：底部显示即将保存的实际负dBm和确认秒数；沿用旧版填`75`自动按`-75`处理的兼容。
- **填推荐值**：仅把3项推荐值填入草稿，明确提示“点击保存后才生效”；取消/返回/点击外部不会写配置。
- **保存并生效**：统一校验3项，错误留在弹窗并聚焦第一项；全部合法才调用原保存入口一次。
- **无静默截断**：越界或解锁/上锁不足6dB缓冲明确指出应填范围；不让用户看到保存成功却暗中把数值改成另一个。
- **滚动与键盘**：字段区可滚动，底部操作区固定，窗口使用键盘resize；说明文字自动换行。没有自动弹出键盘。
- **生命周期**：Activity销毁时关闭窗口；已有窗口显示中时再次点击不会叠加；未保存草稿不进入偏好。

## 4. 代码与不变范围

- `ThresholdSettingsDialog.java`：原生Android卡片、标签/单位、字段错误、预览、推荐草稿及键盘操作，约400行。
- `ThresholdSettingsForm.java`：纯Java解析、范围/6dB缓冲校验及不丢精度的格式化，约110行。
- `MainActivity.java`：读取一次实际配置、展示弹窗和接收合法保存；服务未绑定时也保存同一经过校验的值。
- `ThresholdSettingsFormTest.java`：解析、范围、关系、小数、非有限输入与摘要回归。

`PassiveKeyService`、`PassiveKeyLogic`和`VehicleIdentityStore`与改UI前逐字一致；本轮未改扫描、鉴权、RSSI滤波、解锁/上锁状态机、默认阈值、通知车控、权限或车辆身份。只有用户主动保存才更新配置。

旧弹窗的正数兼容中文注释保留在表单解析方法，原车控/安全注释未删除。

## 6. 真机验收清单（安装后）

1. 主页版本与文件名一致；打开阈值窗口可看到每项标题、用途、单位和推荐范围。
2. 当前有小数配置时显示完整原值，取消关闭后保持原配置。
3. dBm数字键盘可输入负号/小数；Next/Done顺序正常，键盘不遮住操作。
4. 填`-75/-80/4.5`，错误显示在离开信号字段，不关闭窗口；改为`-82`后可保存。
5. 删除值、超范围值或非法粘贴不会写配置；更正后错误消失。
6. 点“填推荐值”后取消不生效；点“保存并生效”才更新主页摘要。
7. 小屏、大字号、窗口收缩时可滚动到第3项和安全提示，不横向截断按钮或单位。
8. 退出Activity没有Window泄漏或叠加弹窗，仍保留原车控安全保护。
