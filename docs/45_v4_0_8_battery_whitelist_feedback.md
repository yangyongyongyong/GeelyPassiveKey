# 45. v4.0.8：电池白名单按钮已加入状态与可见跳转

版本：`4.0.8-min / versionCode 108`。

## 1. 原因

“加入电池白名单”原先始终调用`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`。当应用已经在`dumpsys deviceidle whitelist`中时，系统页面会认为无需申请并立即结束，看起来像按钮没有响应。

本机实测：

```text
user,com.luca.geelykeyradar,10432
```

应用确实已经在白名单中；系统也能解析该Intent，但页面不会停留在申请界面。

## 2. 修复

- 未加入白名单：继续请求系统电池优化豁免。
- 已加入白名单：显示明确Toast，并打开系统电池优化设置列表供用户查看。
- 按钮文案根据实时状态显示“加入电池白名单”或“电池白名单：已加入”。
- 所有Intent失败时给出Toast，不再静默吞掉异常；仍失败则回退到应用详情页。
- 不修改系统白名单状态，不自动替用户授权。

## 3. 验证

- 七组测试、资源、Java、DEX和签名通过。
- 实机安装`4.0.8-min / 108`后，权限卡显示“电池白名单：已加入”。
- 点击该按钮打开vivo系统的后台高耗电/电池设置页，不再无响应。
