# 46. v4.0.9：锁定后台入口与电池设置修正

版本：`4.0.9-min / versionCode 109`。

## 1. 为什么不能直接替用户锁定

OriginOS 的“最近任务锁定”是系统桌面/最近任务卡片的手势功能，不是 Android 公开 API。普通第三方应用不能把自身任务卡片设置成锁定状态，也不能注入最近任务按键；只有系统桌面、设备所有者或 root/定制权限可以做到。

因此本版不伪装成“自动锁定”，而是提供一键说明和系统入口，用户按步骤完成一次即可。

## 2. 使用

权限与保活卡片新增“锁定后台（最近任务说明）”：

1. 从屏幕底部上滑并停留，打开最近任务；
2. 找到“银河无感钥匙”卡片；
3. 长按卡片，或点卡片右上角菜单，选择“锁定”；
4. 再确认自启动和后台高耗电已允许。

同一卡片的“打开后台高耗电设置”现在优先打开系统电池优化页，不再只打开普通应用详情；无法解析时回退到应用详情。

主界面增加`alwaysRetainTaskState=true`，从最近任务重新打开时保留任务状态。

## 3. 已有的真正保活措施

- `connectedDevice`前台服务；
- `START_STICKY`；
- 息屏 `PARTIAL_WAKE_LOCK`；
- 扫描器重试和45秒无广播重建；
- 2分钟服务看门狗；
- 开机/覆盖安装接收器；
- 电池白名单入口。

这些能让系统普通回收后恢复；如果用户在系统里“强行停止”应用，任何应用都无法自行绕过，需要手动重新打开一次。

- “电池白名单：已加入”和“打开后台高耗电设置”均能给出可见结果。
